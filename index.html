عنيAbout Me

مرحباً، أنا عمر عبد الحكيم (M7x) — مطور Full Stack بخبرة تزيد عن 3 سنوات، متخصص في تصميم وبناء تطبيقات ويب جاهزة للإنتاج باستخدام React.js وTypeScript وNode.js وPostgreSQL. بنيت منصات SaaS كاملة تشمل: تصميم REST APIs، تكامل بوابات الدفع وخرائط Google، أنظمة توثيق وصلاحيات (RBAC)، وميزات فورية عبر WebSockets. أُدير خطوط النشر بالكامل على AWS App Runner، مع تحسين الأداء عبر Redis وBullMQ وCloudflare/Bunny CDN.

"لا أتنبأ بالمستقبل... أنا من يبنيه."

Hi, I'm Omar Abd Al-Hakim (M7x) — a Full Stack Developer with 3+ years of experience designing and shipping production-ready web applications using React.js, TypeScript, Node.js, and PostgreSQL. I build complete SaaS platforms: REST API design, payment gateway & Google Maps integration, auth/RBAC systems, and real-time features via WebSockets. I own the full deployment pipeline on AWS App Runner, with Redis, BullMQ, and Cloudflare/Bunny CDN for performance.
